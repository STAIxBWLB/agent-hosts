The plugin control also supplied `{"name":"probe","description":"MCP probe"}` in `plugin.json`. From each workspace, run `agy mcp list`, then `agy -p "Reply with fixture." --output-format stream-json --disable-slash-commands`. The fixture logged requests and flushed responses. All three traces recorded `server/discover` with ID 1, `initialize` with ID 2 and protocol `2025-11-25`, and `tools/list` with ID 3. The matching ID 3 response returned the fixture tool `probe_nonce`.

The direct project file is the supported package shape because it matches the consumers' existing path and completes runtime discovery. The list command's output alone does not establish whether the workspace file loads.
